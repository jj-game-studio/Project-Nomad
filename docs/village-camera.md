# 마을 시점 설정

메인 화면의 **설정 → 마을 시점** 또는 게임의 **ESC → 설정 → 마을 시점** 버튼으로 탑다운과 1인칭을 전환합니다. 기본값은 탑다운이며 선택은 즉시 저장됩니다. 필드에서는 선택과 관계없이 기존 탑다운을 사용하고 마을에 돌아오면 선택한 시점으로 복귀합니다.

## 1인칭 조작

- WASD: 보는 방향을 기준으로 이동합니다. A/D는 옆걸음입니다.
- 마우스: 시선을 회전합니다. 위아래 각도는 제한됩니다.
- E: 가까우면서 화면 중앙에 있는 상호작용 대상을 우선합니다. 기존 거리·벽 차단 판정을 유지합니다.
- Tab, 상점, ESC 설정: 커서가 표시되고 시선·이동 입력이 멈춥니다. 창을 닫으면 복구됩니다.
- Space·Shift: 기존 점프·구르기를 사용하며 카메라는 머리 본의 회전을 따르지 않습니다.

중앙의 작은 점이 시선 기준입니다. 상호작용 대상 위의 기존 E 안내도 같은 우선순위를 사용합니다. 플레이어의 전신 외형은 1인칭 동안 숨기고 탑다운으로 돌아오면 복원합니다. 기존 Kingdom 캐릭터에서 추출한 팔과 장착 무기를 별도로 표시하며 장검 베기, 활 시위 당김, 지팡이 차징/시전을 따릅니다. 이 표시에는 별도 충돌체가 없습니다.

## 구현과 검토

설정은 `Nomad.VillageFirstPerson` PlayerPrefs 값으로 저장합니다. `TopDownCamera`가 플레이어 카메라에 1인칭 제어를 연결하므로 기존 씬·프리팹을 다시 생성할 필요가 없습니다. 새 외부 패키지는 없습니다.

초기 검토값은 눈높이 1.65m, 수직 FOV 70도, 마우스 픽셀당 0.12도, 위아래 각도 ±75도입니다. 화면 흔들림은 추가하지 않습니다. 장검은 짧은 칼끝 궤적으로 표시하며 탑다운용 넓은 베기 면은 가까운 1인칭 화면에서 숨깁니다. 피해·공격 거리·공격 간격 수치는 유지합니다.

Issue #216 / PR #217. Game 씬 또는 MainMenu 씬에서 실행해 설정 변경, 상점 거래, 가방, 필드 왕복을 확인합니다. 조작감·눈높이·시야각은 사람 검토 대상입니다.

## NPC와 안내 표시

NPC의 E 안내는 머리 위에 표시하며 선택은 몸 중심, 거래 거리·벽 차단은 기존 상호작용 지점을 사용합니다. 마을의 필드 출입 안내는 1인칭에서 화면에 수평으로 표시하고 탑다운 전환 시 원래 월드 글자를 복원합니다. 간판 구조물은 원래 위치와 회전을 유지합니다.

팔 에셋 재생성은 `Nomad.PlayerVisual.Editor.FirstPersonArmsAuthoring.Build`를 실행합니다. 원본 ThirdParty를 수정하지 않고 활성 캐릭터의 최고 LOD에서 팔에 속하는 삼각형만 프로젝트 소유 Resources 프리팹·메시로 저장합니다. 런타임에는 원본 전신 리그와 분리해 카메라 공간에서 팔과 무기를 표시합니다.
