# 마을 시점 설정

메인 화면의 **설정 → 마을 시점** 또는 게임의 **ESC → 설정 → 마을 시점** 버튼으로 탑다운과 1인칭을 전환합니다. 기본값은 탑다운이며 선택은 즉시 저장됩니다. 필드에서는 선택과 관계없이 기존 탑다운을 사용하고 마을에 돌아오면 선택한 시점으로 복귀합니다.

## 1인칭 조작

- WASD: 보는 방향을 기준으로 이동합니다. A/D는 옆걸음입니다.
- 마우스: 시선을 회전합니다. 위아래 각도는 제한됩니다.
- E: 가까우면서 화면 중앙에 있는 상호작용 대상을 우선합니다. 기존 거리·벽 차단 판정을 유지합니다.
- Tab, 상점, ESC 설정: 커서가 표시되고 시선·이동 입력이 멈춥니다. 창을 닫으면 복구됩니다.
- Space·Shift: 기존 점프·구르기를 사용하며 카메라는 머리 본의 회전을 따르지 않습니다.

중앙의 작은 점이 시선 기준입니다. 상호작용 대상 위의 기존 E 안내도 같은 우선순위를 사용합니다. 플레이어 자신의 외형은 1인칭 동안 숨기고 탑다운으로 돌아오면 원래 상태로 복원합니다.

## 구현과 검토

설정은 `Nomad.VillageFirstPerson` PlayerPrefs 값으로 저장합니다. `TopDownCamera`가 플레이어 카메라에 1인칭 제어를 연결하므로 기존 씬·프리팹을 다시 생성할 필요가 없습니다. 새 외부 패키지는 없습니다.

초기 검토값은 눈높이 1.65m, 수직 FOV 70도, 마우스 픽셀당 0.12도, 위아래 각도 ±75도입니다. 화면 흔들림·1인칭 전용 손/무기 모델은 포함하지 않습니다.
