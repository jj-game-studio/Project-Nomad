# 필드 조우 배치

맵 전체에 퍼진 일반 몬스터, 먼 엘리트, 외곽 통로 끝의 별도 보스 구역으로 구성합니다.

- 일반은 시작 안전 거리 밖에서 맵 전체에 고르게 퍼뜨리며 검·석궁·지팡이를 번갈아 사용합니다(#154). 적 후보가 퍼진 면적을 (일반+엘리트+1)로 나눈 칸 크기의 80%를 최소 간격으로 시작하고, 자리가 모자라면 간격을 20%씩 줄여(최소 4m) 채웁니다. 이전의 "일반이 엘리트보다 가까운 구간" 규칙은 없앴습니다.
- 거리는 직선 거리만이 아니라 실제 NavMesh 경로 길이로 판단합니다. 엘리트는 보스 접근 경로의 먼 구간을 사용합니다.
- 보스 구역은 먼 외곽의 안전한 연결점을 찾아 필드 밖에 생성합니다. 기본 24×24m 바닥·4m 폭 통로·자체 NavMesh를 갖습니다. 기존 외곽 벽을 지우지 않고 최대 약33° 경사로로 넘으며 원본 지형/상자/경로 결과는 수정하지 않습니다.
- 큰 몬스터가 좁은 후보에 끼지 않도록 등급별 공간과 예약 간격을 확인합니다. 일반 몬스터는 자리가 부족하면 수량을 줄일 수 있습니다. 필수 엘리트/보스는 보행 가능한 후보를 추가 확인하고, 경사로 연결이 불가능하면 E 진입문/귀환문으로 외곽 구역을 연결합니다. 필수 조우를 만들지 못한 Game 필드는 재생성하며 연속 실패 시 마을로 돌아갑니다.
- 재생성·지역 이동 시 구역과 보조 NavMesh/연결을 함께 정리합니다.

수량·안전 거리·구역 크기는 테스트 값입니다. 보스 처치 강제, 문 잠금, 엔딩은 범위 밖입니다. 실제 장비 드롭은 monster-loot.md에 정리합니다.
기본값은 26×26칸 필드 기준 일반12(검·석궁·지팡이 각8), 엘리트1, 보스1입니다. 일반은 시작점 수평12m 밖이며, 엘리트는 보스 접근 경로의60~90% 구간과 시작점18m 밖을 사용합니다.

적용 대상은 현재 게임 진입점인 Game/Field의 FieldMonsters 모듈입니다. 저장된 TerrainIntegration도 같은 배치 로직·드롭을 사용합니다. 가방이 없는 MonsterDebug는 시각적 드롭 검토를 유지합니다.

## 검증

- `Nomad > Monsters > Open Field Encounter Preview` → Play로 현재 메인 필드의 배치 흐름을 검토합니다.
- `scripts/Test-Unity.ps1 -Platform All -Json`: EditMode·PlayMode 회귀 검사.
- `Nomad.Gameplay.Editor.EncounterLayoutVerification.Run`: 저장된 Field.unity를 Play하여 요청 seed0·7·51(지형 실패 시 자동 재시도)의 일반12/엘리트1/보스1, 일반의 사분면 분산(각 1마리 이상, 한 사분면 절반 이하)·도달성·구역 수명과 전경 렌더를 검사합니다.
- 보스 구역은 NavMesh 도달성과 경사로 통로 공간을 검사합니다. 대체 진입문은 실제 CharacterController 입장/귀환 동작을 검사합니다.

## 보스 안내·구역·모션
- 보스 길안내는 플레이어 앞 약5m에 흐린 붉은 바닥 화살표5개로 표시합니다. 미니맵은 별도 길안내 대신 현재 범위 안의 실제 적 위치를 일반(작은 붉은 점)·엘리트(주황 마름모)·보스(큰 붉은 마름모)로 구분합니다. 사망 시 마커를 제거하며, 새 스폰은1초마다 수집합니다. 경로 계산은0.5초마다, 보스 처치/재생성 시 종료합니다.
- 제단은24m 정사각, 저대비 석재 타일·중앙 문양·입구 화로·낮은 낙하 방지 난간입니다. 기존 경사로/다리를 우선 사용합니다. 대체 진입문도 필드에서 도달 가능한 지점에 놓고 안쪽 귀환문을 제공합니다.
- 해골 공격의 회수 구간·연속 공격 재생, 골렘 타격 후 팔 회수/몸 비틀기·보행, 용의 제한된 다리 회전과 보행 전환을 조정했습니다. 공격 판정과 이동/공격속도는 유지합니다. 추가 플레이 피드백으로 엘리트 체력250→220·기본/스킬/원거리 피해20/40/25→18/35/22, 보스 체력1000→850·피해25/45/30→22/40/26으로 소폭 하향했습니다.
- 필수 조우는 관리 목록에도 등록합니다. 정상 조우 생성 후 검토용 전체보기 시점이 남지 않게 플레이 시점으로 복구합니다.
- MonsterProgressionVerification.Run/RunTerrain은 요청 seed와 실제 채택 seed를 구분해 기록합니다. 실패 seed는 기존 지형 재시도 정책을 따르며 필수 조우를 생략하는 성공으로 취급하지 않습니다.

- 보스가 있는 필드는 엘리트1마리를 필수로 생성합니다. 생존 중에는 제단 경계의 물리 봉인과 E 진입문을 모두 잠그고 보스 AI·선제 피해를 막습니다. 엘리트 사망 이벤트 즉시 봉인을 제거하고 보스 전투를 활성화합니다. 필드 재생성 시 잠금도 새로 설정됩니다.

## 복귀 후 정지 방지
- 추격 포기 후 원점으로 돌아가는 동안은 NavMeshAgent 정지거리를 최대0.15m로 줄입니다. 원점0.5m 이내에서 복귀를 끝내고, 원래 전투 정지거리를 되돌린 뒤 다시 탐지합니다.
- 느린 이동속도1.5m/s·전투 정지거리1.2m 조건에서 수정 전 영구 복귀 상태를 재현했고, 원점 도착·재탐지·실제 이동을 회귀 검사합니다.

## 밀도·피격·용 보행 조정
- 메인 필드는 일반12·엘리트1·보스1입니다. 일반의 공격속도 배율은0.9(이전1.25)이며 이동속도/피해와 엘리트·보스 공격 템포는 유지합니다. 저장된 통합 검토 씬은 기존 일반6·엘리트1·보스1 설정을 유지합니다.
- 용 몸통 CapsuleCollider 반경을0.35→1.4m로 넓혔습니다. 날개/꼬리 전체를 맞는 판정으로 만들지는 않으며, 내비게이션 에이전트 반경은 유지합니다.
- 용은 원래 다리 위치·길이·척도를 보존하고, 각 다리의 원래 굽힘 방향으로 두 관절을 풀어 발을 배치합니다. 대각선 두 발이 짝을 이루며 발바닥 방향을 유지합니다. 이동속도에 따라 보행이 섞이고 멈추면 원래 자세로 돌아가며, 사망은 원본 클립을 사용합니다.
- `DragonWalkKeepsLegLengthsAndFootOrientationStable`은 실제 NavMesh 이동 중 네 발의 길이·회전 연속성을 검사합니다. 보스 적중은 실제 단검과 중심에서 비껴간 발사체로 검사합니다.
