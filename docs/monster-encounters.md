# 필드 조우 배치

일반 몬스터 여러 마리 → 먼 엘리트 → 외곽 통로 끝의 별도 보스 구역으로 진행합니다.

- 일반은 시작 안전 거리 밖에서 서로 떨어뜨려 배치하며 검·석궁·지팡이를 번갈아 사용합니다.
- 거리는 직선 거리만이 아니라 실제 NavMesh 경로 길이로 판단합니다. 엘리트는 일반보다 먼 구간을 사용합니다.
- 보스 구역은 먼 외곽의 안전한 연결점을 찾아 필드 밖에 생성합니다. 기본 20×20m 바닥·4m 폭 통로·자체 NavMesh를 갖습니다. 기존 외곽 벽을 지우지 않고 최대 약33° 경사로로 넘으며 원본 지형/상자/경로 결과는 수정하지 않습니다.
- 큰 몬스터가 좁은 후보에 끼지 않도록 등급별 공간과 예약 간격을 확인합니다. 안전한 자리가 부족하면 겹쳐 놓지 않고 부족한 수량을 보고합니다.
- 재생성·지역 이동 시 구역과 보조 NavMesh/연결을 함께 정리합니다.

수량·안전 거리·구역 크기는 테스트 값입니다. 보스 처치 강제, 문 잠금, 보상·드롭 테이블, 엔딩은 범위 밖입니다.
기본값은 일반12(검·석궁·지팡이 각4), 엘리트1, 보스1입니다. 일반은 시작점 수평12m 밖·최소4m 간격이며, 엘리트는 보스 접근 경로의60~90% 구간과 시작점18m 밖을 사용합니다.

적용 대상은 현재 게임 진입점인 Game/Field의 FieldMonsters 모듈입니다. 구 TerrainIntegration·MonsterDebug의 전용 검토 배치는 유지합니다.

## 검증

- `Nomad > Monsters > Open Field Encounter Preview` → Play로 현재 메인 필드의 배치 흐름을 검토합니다.
- `scripts/Test-Unity.ps1 -Platform All -Json`: EditMode·PlayMode 회귀 검사.
- `Nomad.Gameplay.Editor.EncounterLayoutVerification.Run`: 저장된 Field.unity를 Play하여 seed0·7·51의 일반12/엘리트1/보스1, 실제 경로 순서·도달성·구역 수명과 전경 렌더를 검사합니다.
- 보스 구역은 NavMesh 연결뿐 아니라 CharacterController가 기존 벽을 넘어 경사로로 걸어 들어가는 물리 검사도 포함합니다.
