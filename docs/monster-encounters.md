# 필드 조우 배치

일반 몬스터 여러 마리 → 먼 엘리트 → 외곽 통로 끝의 별도 보스 구역으로 진행합니다.

- 일반은 시작 안전 거리 밖에서 서로 떨어뜨려 배치하며 검·석궁·지팡이를 번갈아 사용합니다.
- 거리는 직선 거리만이 아니라 실제 NavMesh 경로 길이로 판단합니다. 엘리트는 일반보다 먼 구간을 사용합니다.
- 보스 구역은 먼 외곽의 안전한 연결점을 찾아 필드 밖에 생성합니다. 바닥·통로·자체 NavMesh를 갖고 원본 지형/상자/경로 결과는 수정하지 않습니다.
- 큰 몬스터가 좁은 후보에 끼지 않도록 등급별 공간과 예약 간격을 확인합니다. 안전한 자리가 부족하면 겹쳐 놓지 않고 부족한 수량을 보고합니다.
- 재생성·지역 이동 시 구역과 보조 NavMesh/연결을 함께 정리합니다.

수량·안전 거리·구역 크기는 테스트 값입니다. 보스 처치 강제, 문 잠금, 보상·드롭 테이블, 엔딩은 범위 밖입니다.
메인 Game/Field와 기존 TerrainIntegration 검토 씬에서 같은 배치 규칙을 사용합니다.
