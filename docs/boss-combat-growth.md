# 보스 전투·장비 강화 검토안 (#214)

사용자 요청은 Issue #214에 보관합니다. 아래 수치는 구현·플레이 검토용 기본값입니다.

필드 이동 없는 테스트: `Assets/Nomad/Monsters/BossDebug.unity`를 열고 Play합니다. 플레이어와 보스만 생성되며 엘리트 해금은 필요 없습니다. 왼쪽 패널에서 무적·자동 패턴·체력/마나 회복·검/활/지팡이 +1·개별 패턴을 선택합니다. R 또는 재시작 버튼은 체력·갑옷·바위를 모두 새로 만듭니다. G는 전방 운석 화염탄 패링입니다.

- 일반 패턴은 차례로 사용하고, 돌진은 발사 후 10초가 지나면 현재 패턴 종료 시 우선 선택합니다.
- 돌진 전조에서는 130도/초로 플레이어를 따라 조준합니다. 마지막 0.45초에는 방향과 거리를 고정해 옆으로 피하거나 바위로 유도할 수 있습니다. 돌진은 바위/벽/플레이어 충돌 또는 NavMesh 끝에서 멈춥니다.
- 이동 6m/s, 가속 18m/s², 회전 150도/초. 크게 돌아야 할 때는 걷기 속도를 낮추며 순간적으로 뒤집지 않습니다. 공격이 끝나면 다음 공격/추적으로 이어집니다.
- 공격 전조는 부드러운 회전을 마칠 시간이 필요하면 연장합니다. 일반 공격의 판정 방향은 준비 시작 시 고정합니다.
- 브레스 입자는 매 프레임 애니메이션이 끝난 실제 머리 위치에서 발사합니다. 불덩이·준비 불꽃도 같은 발사구를 사용합니다.
- 불바닥은 0.75초마다 피해를 주며 이탈하면 추가 피해를 주지 않습니다. 사망/비활성화 시 정리합니다.
- 체력과 독립된 갑옷 내구도는 층마다 1,450이며, 일반 피해는 갑옷 피해 증폭 전 수치만큼 감소시킵니다. 남은 내구도 게이지가 0이 되면 최대 두 번 파괴됩니다. 받는 피해는 100% → 125% → 155%입니다. 파괴 시 공격을 취소하고 4.2초 녹다운 딜타임을 줍니다. 전용 `BossKnockdown.anim`은 넘어짐·쓰러진 자세·일어나기를 가지며 사망 클립과 분리됩니다.
- 기본 체력은 5,200입니다. B등급 검 +1, 치명타 제외, 8초 중 4.4초 일반 공격·C 스킬 / 3.6초 회피 시간을 두는 실제 전투 코드 기준 처치 시간은 120.6초입니다. 무기 등급·강화·공격 기회와 숙련도에 따라 달라지며 무적이나 시간 제한으로 전투를 늘리지 않습니다.
- 보스 타격은 실제 피해 숫자, 타격 지점 불꽃, 짧은 머리 반동·색 변화·충격음·카메라 충격으로 표시합니다. 갑옷 파괴는 더 큰 파편과 파괴음, 0/2~2/2 단계와 받는 피해 배율로 구분합니다.
- 브레스는 외곽 화염·밝은 중심 화염·연기·입 주변 조명을 겹치며, 애니메이션과 반동이 끝난 현재 입 위치에서 발사합니다.
- 플레이어 피격은 보정 후 실제 피해 숫자, 0.24초 상체 반동, 0.55초 붉은 비네트·충격음·짧은 카메라 충격으로 표시합니다. 입력이나 이동을 막지 않고, 회피·무적에는 피격 연출이 나오지 않습니다. 구르기 중 낙하 피해는 숫자/비네트만 표시해 구르기 모션을 덮지 않습니다.
- 바위 충돌은 내구도 65%(942.5)를 감소시킵니다. 파괴가 일어나면 4.2초 녹다운, 파괴되지 않으면 1.1초 짧은 넘어짐입니다. 무적은 주지 않습니다.
- 기절 중에는 머리 위 노란 별 5개만 나타나고, 기절 종료·사망 시 즉시 사라집니다. 기절 글자는 표시하지 않습니다.
- 방은 44×44m입니다. 폭 약 3.4m의 큰 바위 12개를 최소 6m 간격으로 배치하고 중앙·입구/귀환 통로를 비웁니다. 보스는 진입 후 방 밖 8m까지 어그로를 유지하고, 기존 14~15m 추적 제한을 확대합니다.
- 캐릭터 기본 치명타 확률은 10%, 피해 배율은 기존 1.5배입니다. 근접·화살/마법탄·강화 스킬에 치명타 여부를 전달해 큰 주황색 숫자와 `!`로 표시합니다.
- 전방 3갈래 화염탄은 운석 핵·0.65초 화염 꼬리·불씨를 갖습니다. G키는 0.3초 전방 2.5m/140도 안의 화염탄 하나만 반사하며 재사용은 0.9초입니다. 한 번의 판정은 하나만 소비하고 이미 반사한 탄은 다시 반사하지 않습니다. 반사 탄은 보스에 기본 피해 140을 한 번 줍니다. 낙하/불지대 탄은 제외합니다. 통합 씬의 원형 갤러리는 충돌을 피하도록 Shift+G로 이동했습니다.
- 강화는 같은 장비 1개를 소비해 확정 성공, 최대 +3. 강화 상태는 개별 장비와 함께 이동합니다.
- 무기 +1부터 C 스킬: 근접 충격파 / 활 관통 사격 / 지팡이 폭발탄. 8초 쿨다운, 강화로 공격력·스킬 위력 증가. Q 회복약은 유지합니다.
- 방어구 강화는 해당 장비의 방어·기본 스탯을 올립니다. 영구 저장·런 밖 성장은 이번 범위가 아닙니다.
- 장비 창에서 장비칸을 한 번 클릭한 뒤 오른쪽 강화 버튼을 누릅니다. 가방·장비칸은 +수치를 표시합니다.
- 강화 장비도 기존 매입가로 팔 수 있습니다. 판매 창에 강화 소멸을 안내하고, 상점에는 기본 장비로 입고됩니다.

게임 체감·연출·강화 수용은 사람 검토 후 확정합니다. 검증 결과는 PR에 기록합니다.
