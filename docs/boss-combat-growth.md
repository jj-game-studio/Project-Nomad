# 보스 전투·장비 강화 검토안 (#214)

사용자 요청은 Issue #214에 보관합니다. 아래 수치는 구현·플레이 검토용 기본값입니다.

| 패턴 | 전조 | 판정 / 회피 | 후딜 |
| --- | --- | --- | --- |
| 기본 공격 | 0.7초 몸을 젖힘 | 전방 4m, 110도 | 1.4초 |
| 큰 원형 강타 | 2.2초 원형 채움 | 반경 6.5m, 범위 밖으로 이동 | 1.8초 |
| 세 갈래 화염탄 | 0.9초 입에 불꽃 | 바닥 범위 없이 고정 전방 ±22도, 느린 큰 탄 3개 | 1.5초 |
| 원뿔 브레스 | 1.4초 머리를 듦 | 고정 전방 9m·70도, 1.5초 지속 | 1.8초 |
| 화염 지대 투척 | 1.4초 목표 원형 | 목표 고정, 반경 2.4m, 5초 불바닥 | 1.5초 |
| 돌진 | 1.2초 방향 표시 | 고정 방향, 최대 12m, 돌과 벽에 정지 | 1.8초 |
| 작은 불덩이 낙하 | 각 1.1초 원형 | 0.45초 간격 6개, 반경 1.15m, 고정된 위치에 낙하 | 1.8초 |

- 패턴은 즉시 반복하지 않고 차례로 사용합니다. 준비 중 조준을 갱신하지 않습니다.
- 불바닥은 0.75초마다 피해를 주며 이탈하면 추가 피해를 주지 않습니다. 사망/비활성화 시 정리합니다.
- HP 75%·50%를 처음 넘을 때 각 3초 기절합니다. 한 번의 큰 피해로 둘 다 넘으면 기절 하나로 합칩니다.
- 돌무더기에 돌진하면 돌이 부서지고 2.5초 기절합니다. 기절 중 공격은 중단되며 무적은 주지 않습니다.
- 돌은 중앙 반경 5m와 입구/귀환 통로 폭 5m를 피하고, 외곽에 간격을 두어 배치합니다.
- 강화는 같은 장비 1개를 소비해 확정 성공, 최대 +3. 강화 상태는 개별 장비와 함께 이동합니다.
- 무기 +1부터 C 스킬: 근접 충격파 / 활 관통 사격 / 지팡이 폭발탄. 8초 쿨다운, 강화로 공격력·스킬 위력 증가. Q 회복약은 유지합니다.
- 방어구 강화는 해당 장비의 방어·기본 스탯을 올립니다. 영구 저장·런 밖 성장은 이번 범위가 아닙니다.
- 장비 창에서 장비칸을 한 번 클릭한 뒤 오른쪽 강화 버튼을 누릅니다. 가방·장비칸은 +수치를 표시합니다.
- 강화 장비도 기존 매입가로 팔 수 있습니다. 판매 창에 강화 소멸을 안내하고, 상점에는 기본 장비로 입고됩니다.

게임 체감·연출·강화 수용은 사람 검토 후 확정합니다. 검증 결과는 PR에 기록합니다.
