# 보스 전투·장비 강화 검토안 (#214)

사용자 요청은 Issue #214에 보관합니다. 아래 수치는 구현·플레이 검토용 기본값입니다.

필드 이동 없는 테스트: `Assets/Nomad/Monsters/BossDebug.unity`를 열고 Play합니다. 플레이어와 보스만 생성되며 엘리트 해금은 필요 없습니다. 왼쪽 패널에서 무적·자동 패턴·회복·장비·개별 패턴을 선택합니다. 패턴 선택 뒤 아래 개수/속도/범위 슬라이더를 바꾸고 `선택 패턴 실행`을 누릅니다. R은 체력·갑옷·바위·수치를 초기화하고 무적 토글은 유지합니다. F는 노란 섬광 패링입니다. 디버그 무적은 구르기 무적과 분리하며 낙하 피해도 막습니다.

개별 패턴 버튼은 자동 패턴 체크를 유지합니다. 체크한 상태에서는 선택한 공격 뒤 자동 전투를 계속하고, 체크를 껐을 때만 한 번 실행합니다.

- 기본 공격은 자동 순서와 디버그 선택지에서 제거했습니다. 옛 enum 인덱스만 보존하며 직접 요청해도 실행하지 않습니다. 나머지 패턴은 직전 패턴을 제외해 무작위 선택합니다. 근접 8m 이내에서만 몸 휘두르기를 후보에 넣고, 돌진은 발사 후 최소 34초가 지나야 후보가 됩니다. 추적 중에는 뽑은 후보를 유지합니다.

- 보스는 단계적인 명암과 검은 외곽선을 사용합니다. 마우스 레이가 실제 보스 피격체와 겹치면 0.12m 굵기의 붉은 윤곽선으로 바뀝니다. 플레이어는 머리 위에 별도 체력바를 표시합니다.
- 조우 전에는 본체·보스 체력·파괴 UI와 피격 충돌체를 숨깁니다. 플레이어가 보스방 중심 14m 안으로 들어오면 반경 6m 위험 원형을 1.2초 보여주고, 12m 높이에서 0.65초간 낙하합니다. 착지 후 전투/UI가 시작됩니다. 고정 스폰 원형 장식은 제거했습니다.
- 사망은 전용 `BossDeath.anim`으로 2.6초간 옆으로 쓰러지고 마지막 자세를 유지합니다. 일반 이동 애니메이션/다리 보정을 멈추므로 녹다운 후 일어나는 모션과 섞이지 않습니다.
- 돌진 전조에서는 130도/초로 플레이어를 따라 조준합니다. 마지막 0.45초에는 방향과 거리를 고정합니다. 플레이어와 닿아도 접촉 피해는 한 번만 주고 지나쳐 달립니다. 바위/벽/지형 끝에서는 멈추며, 경고 직사각형도 방 경계에서 잘립니다.
- 이동 6m/s, 가속 18m/s², 회전 150도/초. 크게 돌아야 할 때는 걷기 속도를 낮추며 순간적으로 뒤집지 않습니다. 공격이 끝나면 0.85초 회복 후 다음 공격/추적으로 이어집니다.
- 공격 전조는 부드러운 회전을 마칠 시간이 필요하면 연장합니다. 일반 공격의 판정 방향은 준비 시작 시 고정합니다.
- 브레스 입자는 매 프레임 실제 턱 높이를 따르며, 입자 반경까지 여백을 두어 3.5m 안전 구간과 18m 사거리 밖으로 넘치지 않게 합니다. 바닥 전조도 안쪽이 뚫린 같은 부채꼴입니다. 불덩이·준비 불꽃도 같은 발사구를 사용합니다.
- 불바닥은 0.75초마다 피해를 주며 이탈하면 추가 피해를 주지 않습니다. 사망/비활성화 시 정리합니다.
- 체력과 독립된 갑옷 내구도는 층마다 1,450입니다. 반사 화염탄은 45%(652.5), 바위 충돌은 65%(942.5), 기본 공격은 갑옷 증폭 전 피해의 15%(한 번에 최대 12)를 깎습니다. 강화 스킬은 체력 피해만 줍니다. 남은 내구도 게이지가 0이 되면 최대 두 번 파괴되며 받는 피해가 55% → 100% → 185%로 증가합니다. 파괴 시 공격을 취소하고 5초 녹다운 딜타임을 줍니다. 전용 `BossKnockdown.anim`은 넘어짐·쓰러진 자세·일어나기를 가지며 사망 클립과 분리됩니다.
- 기본 체력은 4,200입니다. B등급 검 +1, 치명타 제외, 8초 중 4.4초 일반 공격·C 스킬 / 3.6초 회피 시간을 두는 실제 전투 코드 기준 처치 시간은 116.4초(일반 공격 105회·스킬 15회, 45/85초에 패링 반격+바위 수치로 두 단계 파괴)입니다. 무기 등급·강화·공격 기회와 패링/바위 유도에 따라 달라지며 무적이나 시간 제한으로 전투를 늘리지 않습니다.
- 보스 타격은 실제 피해 숫자, 타격 지점 불꽃, 짧은 머리 반동·색 변화·충격음·카메라 충격으로 표시합니다. 갑옷 파괴는 더 큰 파편과 파괴음, 0/2~2/2 단계와 받는 피해 배율로 구분합니다.
- 브레스는 외곽 화염·밝은 중심 화염·연기·입 주변 조명을 겹치며, 애니메이션과 반동이 끝난 현재 입 위치에서 발사합니다.
- 플레이어 피격은 보정 후 실제 피해 숫자, 0.24초 상체 반동, 0.55초 붉은 비네트·충격음·짧은 카메라 충격으로 표시합니다. 입력이나 이동을 막지 않고, 회피·무적에는 피격 연출이 나오지 않습니다. 구르기 중 낙하 피해는 숫자/비네트만 표시해 구르기 모션을 덮지 않습니다.
- 바위 충돌은 내구도 65%(942.5)를 감소시킵니다. 파괴가 일어나면 5초 녹다운, 파괴되지 않으면 2.8초 넘어짐입니다. 무적은 주지 않습니다.
- 회전하는 별은 제거했습니다. 녹다운 자세와 내구도/파괴 표시로 상태를 확인합니다. 기절 글자도 표시하지 않습니다.
- 방은 지름 44m의 원형 경기장입니다. 실제 지면 메시/충돌/NavMesh와 난간을 원형으로 맞추고, 바깥에는 깎인 현무암 절벽·용암/용암 폭포·부서진 아치·붉은 깃발/화로를 배치했습니다. 현재 보유 바위 에셋과 절차형 장식/셰이더를 쓰며 추가 구매 에셋은 없습니다. 폭 약 3.4m의 바위 8개로 시작하며 최소 6m 간격과 중앙·입구/귀환 통로를 비웁니다. 노란빛 패링 성공 때 2~3개가 안전 위치에서 솟아오르고, 0.65초 뒤 착지해야 통행을 막습니다. 누적 16개를 넘으면 플레이어/보스와 먼 오래된 돌부터 교체합니다. 보스는 진입 후 방 밖 8m까지 어그로를 유지합니다.
- 보스 추적은 일반 몬스터의 시야 상실·귀환 상태와 분리합니다. 방에 재진입하면 정지를 해제하고 경로를 다시 잡으며, 길이 막히면 2.5초 후 원거리 패턴으로 이어가 영구 대기를 막습니다. 일반 몬스터의 추적 규칙은 유지합니다.
- 바닥은 중앙/입구를 평탄하게 두고 외곽에 최대 약 0.7m의 완만한 굴곡을 줍니다. 실제 충돌 메시와 NavMesh가 같은 지면을 사용하고, 원형/돌진 경고와 균열도 지면 높이를 따릅니다. 균열은 3.5초간 남는 착지 연출이며 물리적인 구멍을 만들지는 않습니다.
- 캐릭터 기본 치명타 확률은 10%, 피해 배율은 기존 1.5배입니다. 근접·화살/마법탄·강화 스킬에 치명타 여부를 전달해 큰 주황색 숫자와 `!`로 표시합니다.
- 화염탄은 큰 구체 메시와 불꽃·불씨·잔광을 함께 사용합니다. 금빛 신호는 피해 예상 시각 0.45초 전에 윤곽/교차 섬광/불꽃으로 표시하며 몸을 단색으로 칠하지 않습니다. F 입력 창 0.5초·재사용 0.9초, 공격/차징 중 취소 가능입니다. 화염탄은 실제 구체가 플레이어 전방 160도/구체 반경+0.85m 안에 들어왔을 때 하나만 반사합니다. 구체가 없으면 신호만으로는 성공하지 않으며 다른 구체를 삭제하지 않습니다. 반사 탄은 보스 HP 피해 없이 내구도 45%만 깎습니다. 성공한 발사 묶음 전체의 플레이어 피해를 막고 같은 프레임에 먼저 닿은 다른 탄의 피해도 취소합니다. 다른 발사 묶음은 별도 패링이 필요합니다. 강타와 몸 휘두르기 저스트 가드도 HP 피해 없이 내구도 45%만 깎고, 해당 공격의 피해/밀침을 취소합니다. 낙하/불지대 탄은 패링 대상이 아닙니다. 통합 씬 가방 채우기는 Shift+F, 갤러리는 Shift+G입니다.
- 원형·돌진 경고는 실제 지면 위 0.22m, 경계는 0.25m로 투영해 굴곡에 묻히지 않게 합니다. 녹다운은 발의 원래 위치를 유지하면서 앞/뒷무릎을 접고 가슴과 머리를 내린 뒤 일어납니다. 전용 다리 보정은 녹다운 동안 중지하며 사망과 별도 클립을 사용합니다.
- 전투 UI는 상단 검정/금색 장식과 붉은 보스 체력/현재 수치·얇은 파괴 게이지, 하단 검정/금색 프레임·HP·MP/STM 원형 게이지입니다. 기존 6칸 퀵슬롯과 클릭/드래그/등록 규칙은 유지합니다. 하단 스킨은 기존 PlayerHud Canvas 아래에 두어 설정 표시 토글을 그대로 따르고 종료 시 레이아웃을 복원합니다. 디버그 장비 버튼은 현재 무기를 1번 퀵슬롯에도 등록합니다.
- 강화는 같은 장비 1개를 소비해 확정 성공, 최대 +3. 강화 상태는 개별 장비와 함께 이동합니다.
- 무기 +1부터 C 스킬: 근접 충격파 / 활 관통 사격 / 지팡이 폭발탄. 8초 쿨다운, 강화로 공격력·스킬 위력 증가. Q 회복약은 유지합니다.
- 방어구 강화는 해당 장비의 방어·기본 스탯을 올립니다. 영구 저장·런 밖 성장은 이번 범위가 아닙니다.
- 장비 창에서 장비칸을 한 번 클릭한 뒤 오른쪽 강화 버튼을 누릅니다. 가방·장비칸은 +수치를 표시합니다.
- 강화 장비도 기존 매입가로 팔 수 있습니다. 판매 창에 강화 소멸을 안내하고, 상점에는 기본 장비로 입고됩니다.

게임 체감·연출·강화 수용은 사람 검토 후 확정합니다. 검증 결과는 PR에 기록합니다.

## 품질 후속 검토

- 패링 성공 때만 노란 `패링!` 팝업과 강화한 금빛 섬광/불꽃을 표시합니다.
- 광폭 눈 밖으로 떠 있던 붉은 구체를 제거하고 눈 표면 발광·몸의 열 균열·작은 불씨로 표현합니다. 전조/발사 중 날개·턱·꼬리를 패턴별로 보정하며 사망/녹다운에는 적용하지 않습니다.
- 플레이어·일반/엘리트 몬스터·보스방 바위에 단계 명암/얇은 외곽선을 적용합니다. 원본 재질/에셋은 변경하지 않습니다.
- 보스방은 깎인 동심원 석판과 틈, 층진 기단, 실제 석조 기둥/아치, 추가 절벽으로 보강했습니다. 일반 상자는 유지하고 보스 전용 상자만 2.8m 크기의 실제 뚜껑/금속 장식 상자와 금빛 불씨/조명을 사용합니다.
- 등장 낙하/점프 강타는 0.25초·진폭 0.42 카메라 충격을 줍니다. 불지대는 검은 껍질·움직이는 용암 균열·밝은 가장자리/불씨로 표시합니다.
- 디버그에서 패턴 사이 회복 시간과 광폭 화염우 장판 확률도 조절할 수 있습니다.

## 패링·2페이즈 후속

- 화염탄 노란 사거리와 플레이어 발밑 원호가 도달 예정 시각까지 차오릅니다. 완성 시점에 F를 누르며, 실제 구체가 접근해야 패링됩니다. 사거리 경계는 경기장 통행 경계 안에서 자릅니다.
- 불지대의 메시/경고/불씨/셰이더와 피해 판정은 같은 고정된 굴곡 경계를 사용합니다. 원형 원판만 찌그러뜨려 피해가 바깥에 남는 방식은 쓰지 않습니다.
- 보스 HP바에 피해 잔상·불꽃을 추가하고 전환/2페이즈 광폭을 별도로 표시합니다. 입력 잠금은 기존 디버그/메뉴 잠금과 독립되어 종료 뒤 원래 기능을 유지합니다.
