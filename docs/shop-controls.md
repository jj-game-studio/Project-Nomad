# 상점 조작과 화면 확인

`Nomad > Shop > Open Shop Debug`에서 Play 후 상점 근처 E로 엽니다. 통합 게임의 마을 상점도 같은 UI를 사용합니다.

기본 화면에는 가방과 상품 목록만 표시합니다. 아이템을 클릭하면 중앙에 큰 이미지·설명·단가·총액·거래 후 잔액과 수량 슬라이더가 있는 팝업을 엽니다. 상품은 구매, 가방 아이템은 판매 버튼을 표시합니다. 하단 거래 영역은 없습니다.

| 입력 | 목록 | 거래 팝업 |
| --- | --- | --- |
| 좌클릭 | 해당 아이템 팝업 열기, 수량 1개 | 버튼·정수 슬라이더·수량 직접 입력 |
| Shift + 좌클릭 | 최대 수량으로 팝업 열기. 거래하지 않음 | — |
| 우클릭 | 아무 동작 없음 | 거래 없이 팝업 닫기 |
| 방향키 / Tab | 아이템 선택 / 가방·상품 전환 | Tab·Shift+Tab으로 활성 조작 대상 이동, 금색 테두리 강조 |
| Enter | 선택 아이템 팝업 열기 | 포커스 버튼 실행. 포커스가 없으면 거래, 수량 입력 중이면 입력만 확정 |
| Q / +·− | — | 수량 직접 입력 / 증감 |
| B / V | 구매 / 판매 팝업 열기 | 구매 / 판매 실행 |
| L | 선택 가방 아이템 판매 잠금 / 해제 | 판매 잠금 / 해제 |
| E / Esc | 상점 닫기 | 팝업만 닫기 |

최대 수량은 구매 시 재고·골드·가방 공간, 판매 시 선택 슬롯의 보유 수량입니다. 잠긴 아이템은 판매할 수 없습니다. 거래 후 팝업을 유지하고 결과를 표시합니다. 품절·전량 판매·한도 0에서는 수량과 거래를 비활성화합니다.

팝업과 슬롯은 고정 위치·크기를 사용하며, 마우스 선택으로 목록을 스크롤하지 않습니다. 관성 스크롤을 끄고 키보드로 화면 밖 항목에 이동할 때만 필요한 만큼 스크롤합니다.

검증: `Nomad.Shop.Editor.ShopVerification.Run`은 실제 클릭·슬라이더·수량 입력·팝업 닫기·판매 잠금·필터·거리 이탈·사망·재입고를 확인하고 `UnityProject/Artifacts/shop-list.png`, `shop-popup-*.png`를 저장합니다. 글꼴 출처와 OFL은 `Assets/StreamingAssets/ThirdPartyLicenses/ShopFonts`에 있습니다.

기본 화면은 안내 문장·단축키 꼬리표를 표시하지 않습니다. ? 버튼 또는 F1로 조작 도움말을 열고, Esc로 도움말부터 닫습니다. 팝업은 아이템 정보 → 수량 → 총액/잔액 → 취소·거래 순서이며 판매가는 판매 팝업에서 확인합니다. 제목은 주아체, 설명·입력 숫자는 Pretendard를 사용합니다.
