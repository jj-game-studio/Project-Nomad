# 상점 조작과 화면 확인

`Nomad > Shop > Open Shop Debug`에서 테스트 씬을 열고 Play 후 상점 가까이에서 E를 누릅니다. 통합 플레이에서는 마을 상점에서도 같은 UI를 사용합니다.

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 아이템 선택, 거래 수량 1개 |
| Shift + 좌클릭 | 해당 아이템 전량 선택. 거래는 실행하지 않음 |
| 우클릭 | 선택한 아이템이면 입력 수량 거래. 다른 아이템이면 1개를 선택해 거래 |
| 방향키 | 현재 목록 안에서 이동. 가방 5열, 상점 3열 |
| Tab | 가방 / 상점 목록 전환 |
| Q | 수량 입력 칸 활성화. 숫자 직접 입력 가능 |
| + / − | 수량 증감 |
| Enter | 선택 수량 거래. 수량 입력 중이면 입력만 확정 |
| B / V | 구매 / 판매 |
| L | 가방에서 선택한 아이템 판매 잠금 / 해제 |
| E / Esc | 상점 닫기. 수량 입력 중이면 먼저 입력 종료 |

판매 잠금, 골드·재고·가방 공간 제한은 우클릭에도 동일하게 적용합니다. 전량과 구매 한도는 수량만 바꾸므로 거래 실행 전에 합계를 확인할 수 있습니다.

화면은 녹색 헤더·크림색 본문·금색 선택 테두리, 큰 상점 카드와 작은 가방 슬롯으로 구성합니다. 글꼴은 Pretendard Regular / SemiBold이며 출처와 OFL은 `Assets/StreamingAssets/ThirdPartyLicenses/ShopFonts`에 보관합니다.

자동 확인: `Nomad.Shop.Editor.ShopVerification.Run` 배치 검증은 실제 UI 입력·구매/판매·판매 잠금·필터·재입고·우클릭·Q 수량 입력을 확인하고 `UnityProject/Artifacts/shop-ui*.png`를 저장합니다. 최종 미술 방향은 사람의 화면 검토가 필요합니다.
