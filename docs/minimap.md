# 마을·필드 미니맵

`Game.unity`를 재생하면 마을과 필드의 오른쪽 위에 작은 지도가 자동으로 표시됩니다. 등록된 Village/Field 씬을 단독 재생해도 같은 HUD가 설치됩니다. 기존 씬, PlayerRig, GameConfig를 수정하지 않으므로 콘텐츠 재생성 후에도 유지됩니다.

- 북쪽 고정, 플레이어 위치와 바라보는 방향(흰 화살표), 지역 이름
- 출구: 파란 마름모 / 상점: 금색 사각형. 현재 지역의 실제 컴포넌트를 수집합니다.
- 마을: Collider로 장애물을 구분하고 배치된 잔디·흙 메시를 단순한 색으로 투영합니다.
- 필드: 최종 NavMesh의 이동 가능한 지형과 높낮이를 투영합니다. 재생성 완료마다 지도를 교체합니다.
- 인벤토리·상점 등 입력 가능한 창, 로딩, 일시정지 중에는 숨깁니다. 미니맵은 마우스 입력을 가로채지 않습니다.

지도는 지역 변경/재생성 때 96×96 텍스처로 한 번 만들며, 매 프레임에는 아이콘 위치만 갱신합니다. 추가 카메라를 사용하지 않고 이전 텍스처·아이콘·이벤트 구독을 해제합니다.

## 현재 범위

필드는 현재 던전 역할의 탐험 지역입니다. 탐험 안개·적·숨겨진 상자·확대 지도는 이번 범위에 포함하지 않습니다. 이미 생성된 지역의 전체 형태를 보여줍니다. 마을의 장식 메시 투영은 단순화한 외곽이며 정밀한 충돌 지도는 아닙니다. TerrainIntegration 등 기존 개발용 씬은 GameConfig 등록 지역이 아니므로 설치 대상에서 제외합니다.

## 검증

- `scripts/Test-Unity.ps1 -Platform All -Json`: EditMode/PlayMode 회귀 검사. MinimapProjectionTests는 좌표·비율·마커 경계와 왕복 변환을 확인합니다. 지역별 데이터 교체는 아래 실제 씬 검증으로 확인합니다.
- Unity 배치 `-executeMethod Nomad.Minimap.Editor.MinimapVerification.Run`: 실제 Game→Village→Field→필드 재생성→Village 왕복, 위치·방향·마커·창 입력·자원 해제 검증. `UnityProject/Artifacts/minimap-*.png`에 화면을 저장합니다.

지도의 크기와 시인성은 사람의 플레이 검토가 필요합니다.
