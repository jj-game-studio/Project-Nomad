# 가방 아이템 분할

- 기존 가방 화면에서 수량 2개 이상인 아이템을 Ctrl+좌클릭합니다. Shift+클릭 상자 전송은 유지합니다.
- 슬라이더 또는 숫자 입력으로 1~현재수량-1개를 선택합니다. 초기값은 절반(홀수 내림)입니다.
- 분할 버튼/Enter로 확정하면 첫 빈 가방칸에 별도 스택이 생성됩니다. 같은 아이템의 기존 스택에는 합치지 않습니다.
- 취소/Esc는 창만 닫고, Tab은 분할 창과 가방을 닫습니다. 포커스 상실도 취소합니다.
- 가방 만석·범위 밖 수량·원본 변경 시 수량은 바뀌지 않습니다. 원본 변경 시 창을 다시 엽니다.
- 분할 중 뒤쪽 가방·장비·퀵슬롯 입력을 차단합니다. 퀵슬롯 등록과 전체 보유 수량을 유지합니다.

## 적용 범위와 후속

현재는 플레이어 가방에서만 사용합니다. **상점 화면에는 적용하지 않으며, 상점 분할 적용이 후속으로 필요합니다.**
상자 내부 스택 분할·수량 지정 전송·가방 용량 변경은 이번 범위에 포함하지 않습니다.

## 검토

`Nomad > Inventory > Open Stack Split Preview`에서 기존 인벤토리 씬을 열고 Play 후 Tab을 누릅니다.
중첩 가능한 Scrap을 Ctrl+좌클릭하여 확인합니다. 검증 결과는 연결 PR #107에 기록합니다.
