# 커서 방향 카메라 (#108)

`TopDownCamera`는 기존 `target` 참조와 (0,12,-8)m 오프셋·고정 회전·FOV50을 유지합니다. 플레이어 이동을 즉시 따라가고 커서에 따른 수평 이동만 보간합니다. 덕코프에서 착안한 개념 시뮬레이션의 수용을 바탕으로 하며 원본 게임의 내부 구현·수치를 재현하지 않습니다.

## 설정과 입력

- `Max Look Ahead`: 최대 수평 거리, 기본2m. 0이면 추가 이동을 즉시 비웁니다.
- `Smooth Time`: 기본0.15초. 시뮬레이션과 같은 지수 보간(이 시간에 목표 변화의 약95% 반영), 0이면 즉시 반영. UI 복귀는 unscaled 시간으로 일시정지 중에도 진행합니다.
- `Dead Zone`: 기본0.1. 카메라 pixelRect 중심에서 반너비·반높이로 정규화한 반경입니다. 대각선은 원형 상한으로 제한합니다.
- 기준은 움직인 플레이어의 화면 위치가 아닌 고정된 화면 중앙입니다. 커서를 고정해도 카메라가 계속 밀리지 않습니다. 지형 레이 충돌 결과를 쓰지 않아 절벽/장애물에서 카메라 이동량이 튀지 않습니다.
- 마우스 없음·포커스 상실·일시정지·입력 UI가 열려 있으면 추가 이동 목표는0입니다. 커서 화면 이탈은 각 축을 카메라 pixelRect 가장자리로 제한해 최대 이동량을 유지합니다. 위·아래 툴바 방향으로 나가도 포커스가 유지되는 동안 중앙으로 복귀하지 않습니다. 다른 창 클릭 등으로 포커스를 잃으면 중앙으로 복귀합니다. 기존 HUD는 입력용 GraphicRaycaster가 없으므로 카메라를 멈추지 않습니다.
- 입력 UI 판정은 활성 GraphicRaycaster에 실제로 입력을 받는 활성 Graphic이 있는지 검사합니다. 가방/상자/상점 바깥에 커서가 있어도 복귀하며, CanvasGroup의 입력 차단도 존중합니다. 이후 항상 표시되는 클릭형 HUD를 추가하면 이 판정과 역할을 나누어야 합니다.

## 초기화와 통합

카메라는 LateUpdate 순서50에서 갱신하고 PlayerCombat(100)의 조준 계산보다 먼저 반영됩니다. 월드 HUD는 렌더 직전 최종 카메라로 투영하는 기존 동작을 유지합니다.

대상 교체·비활성화·카메라 재활성화 또는 프레임 간 이동이 `max(0.5m, 12m/s × deltaTime)`를 넘으면 이전 이동량을 비웁니다. 이 기준보다 작은 순간이동을 수행하는 코드는 `TopDownCamera.ResetTracking()`을 호출해야 정확히 초기화됩니다. PR #95의 미병합 PlayerRig/지역 전환 코드는 수정하지 않습니다. 해당 통합 시 이 API를 작은 순간이동에도 연결할 수 있습니다.

`TerrainIntegration.unity`에는 기본값을 명시적으로 저장합니다. 다른 기존 씬·새 컴포넌트는 필드 초기값을 사용합니다.

## 검토

`Nomad > Player > Verify Cursor Camera Settings`는 저장된 TerrainIntegration 카메라 설정을 확인합니다. Test Runner의 PlayMode `Nomad.Camera.PlayModeTests`가 격리된 실제 프레임·입력·가방·조준/HUD 검증입니다. `Nomad > Terrain > Open Integration Test Scene` → Play에서 WASD/점프/구르기와 커서 좌우·상하·대각선 이동, Tab 가방, E 상자를 확인합니다.

실제 Unity 이동량·방향 전환 체감은 @VirtualExplorer7613의 플레이 검토 대상입니다. 시뮬레이션 승인은 구현 지시이며 완성된 Unity 결과의 병합 승인을 뜻하지 않습니다.

자동 검증: Unity6000.6.9f1 PlayMode8/8 통과. 고정 커서 드리프트·상하좌우/대각선 제한·중앙 영역·실제 시간 보간·상하좌우·네 모서리 경계 왕복/화면 밖 가장자리 유지·UI/포커스/일시정지 복귀·대상 교체/순간이동/재활성화·부분 viewport·이동한 카메라의 조준점/스태미나 HUD 위치를 확인했습니다. 저장 통합 씬의 실제 WASD 이동·E 상자 열기·Tab 닫기·O 전체보기 왕복도 통과했습니다. 카메라 렌더 캡처는 Overlay UI를 포함하지 않습니다. Windows 빌드·사람 조작감 검토 및 미병합 상점/지역 모듈 통합은 실행하지 않았습니다.
