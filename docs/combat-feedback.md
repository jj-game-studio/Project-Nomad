# 보스 조우·타격 피드백·회복약

- 잠금 해제된 보스방 안에서는 플레이어 시야 제한을 풀어 보스·환경·전리품을 모두 표시합니다. 퇴장·비활성화·재생성 시 기존 필드 시야로 복구합니다. 마을의 시야 설정은 따로 유지합니다.
- 피격 효과는 아래 전투 피드백 조정 절을 따릅니다. 전투 시간/공격 간격/이동은 멈추지 않습니다. 기존 테스트 패널의 `Hit flash` 토글은 반짝임만 제어하며, 카메라 충격은 새 디버그 창에서 독립적으로 제어합니다. 카메라 변위는 렌더 종료 때 복원합니다.
- 필드 출구는 접촉만으로 지역을 전환하지 않습니다. 가까이에서 E를 눌러 `마을로 귀환`을 선택합니다. 사망 후 R 재시작·생성 실패 복구 정책은 그대로입니다.
- 체력 회복약: Q 사용,40 회복, 시작3개, 최대중첩10, 사용간격0.6초. 만피/사망/일시정지/거래·장비·상자 창 또는 입력 차단 중에는 소모하지 않습니다. HUD에 `Q 회복약 ×수량`을 표시합니다.
- 마을 상점 소모품에서40G에 구매,15G에 판매, 초기재고20개입니다. 회복약은 독립 ItemDefinition이며 #184의 상자 드롭 테이블은 수정하지 않습니다.

## 저작·검증

- `Nomad > Items > Refresh Health Potion`: 아이템·아이콘, 실제 PlayerRig 카탈로그/시작 지급/사용 컴포넌트, 상점 상품을 중복 없이 갱신합니다. 장비/상점 전체 저작기로 재생성했다면 마지막에 실행합니다.
- `HealthPotionTests`: 실제 PlayerRig의 Q 사용·수량·최대 체력·사망/UI 차단·실제 단검/갑옷 장착·상점 보충 데이터를 검사합니다.
- `GameBootstrapTests`: 필드 출구를 밟아도 전환 없음, 실제 E 입력 후 정상 귀환을 검사합니다.
- `MonsterProgressionVerification.Run/RunTerrain`: Game과 저장된 TerrainIntegration의 필수 조우·봉인·보스방 시야 개방/퇴장 복구·드롭/정리를 검사합니다. TerrainIntegration YAML은 #184 선점 영역이라 수정하지 않습니다.

## 전투 피드백 조정

Issue #214의 후속 작업입니다. 일반 몬스터 적중 효과와 플레이어 피격 비네트를 개선하며 기존 보스 패턴·피해 판정·수치는 유지합니다.

## 동작

- 일반 몬스터는 `Health.Damaged`가 전달한 실제 피해량마다 즉시 반짝임·숫자·파편·타격음·카메라 충격을 재생합니다. 같은 프레임의 일반/치명타도 별도 숫자로 구분합니다.
- 일반 반짝임 0.09초, 치명타 0.13초. 일반 파편 8개, 치명타 16개이며 개체당 최대 48개입니다. 데미지 숫자는 개체당 최대 8개입니다.
- 몬스터 타격음은 전체 몬스터에서 0.04초 간격으로 제한합니다. 카메라 충격은 더하지 않고 가장 강한 요청을 유지합니다. 플레이어 피격음은 몬스터 타격음 제한에 막히지 않습니다.
- 플레이어 비네트는 등장 0.04초 → 유지 0.05초 → 복귀 0.35초입니다. 화면 중앙을 투명하게 유지하고 피해량에 따라 최대 강도 0.6까지 반응합니다.
- 연속 피격은 남아 있는 피크보다 약해지지 않으며, 현재 보이는 강도에서 새 곡선을 시작합니다. 효과가 끝난 뒤에는 새 피해량을 기준으로 시작합니다.
- 구르기 무적·회피·회복에는 실제 피해 이벤트가 발생하지 않아 피격 효과도 없습니다. 낙하 등 실제 HP 감소는 기존처럼 피격 효과를 재생합니다.
- 일시정지에서는 효과 수명이 멈춥니다. 비활성화 시 잔여 효과를 지우고 재활성화 시 이전 피해를 재생하지 않습니다.

## 디버그 사용법

1. Unity에서 Game 또는 전투 테스트 씬을 Play합니다.
2. `Nomad > Debug > 전투 피드백` 창을 엽니다.
3. `현재 씬에서 대상 찾기`를 누르거나 Hierarchy의 플레이어/일반 몬스터를 각각 지정합니다. 대상은 해당 피드백 컴포넌트가 있어야 합니다.
4. `플레이어 피격`, `몬스터 적중`, `플레이어 연속 3회`로 재생합니다. 테스트 피해량은 연출용이며 HP·피해 판정·어그로를 변경하지 않습니다. 반짝임에 연결된 기존 피격 애니메이션은 함께 재생될 수 있습니다.
5. 효과별 토글과 시간·강도·색·음량 슬라이더로 조정합니다. 일반 몬스터 전용 테스트 패널의 토글이 꺼져 있으면 해당 효과는 이 창에서 켜도 꺼진 상태를 유지합니다.
6. `재생 중인 효과 지우기`는 모든 활성 플레이어/일반 몬스터의 피드백과 카메라 충격을 정리합니다. `설정 기본값 복원`은 디버그 설정도 복원합니다.
7. `현재 설정 JSON 복사`로 조정값을 복사해 검토 기록에 남길 수 있습니다.

이 창은 Editor 전용이며 Play 중 설정은 세션 전체와 새로 생성되는 대상에도 적용됩니다. Play 재시작 시 기본값으로 돌아갑니다. 설정을 제품 기본값으로 확정하려면 `CombatFeedbackSettings`의 초기값을 변경하고 재검증합니다. 일시정지 중 미리보기는 재생되지 않습니다.

## 검토 기준

- 실제 공격의 적중 순간과 반짝임·숫자·소리가 일치하는지 확인합니다.
- 치명타와 일반 적중을 구분할 수 있는지, 다수 적을 동시에 때려도 소리와 흔들림이 과하지 않은지 확인합니다.
- 플레이어 피격 시 화면 중앙·바닥 위험 예고·다음 공격을 계속 읽을 수 있어야 합니다.
- 약한 연속 피격, 큰 피해 뒤 작은 피해, 구르기 무적, 사망, 일시정지·재개, 씬 전환을 확인합니다.
- 자동 검사: EditMode `Nomad.Tests.CombatFeedbackTests`, PlayMode `Nomad.Monsters.Tests.MonsterHitFeedbackTests`. 보스 통합 회귀는 기존 `DragonBossCombatTests`를 사용합니다.

최종 강도·색·소리·반짝임과 카메라 충격의 수용 여부는 사람 Play 검토 대상입니다.
