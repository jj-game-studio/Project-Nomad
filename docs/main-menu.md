# 메인 화면

`Assets/Nomad/MainMenu/MainMenu.unity`를 열어 Play합니다. 메뉴는 새 게임·설정·게임 종료이며 이어하기는 없습니다. 빌드는 MainMenu → Game → 기존 시작 지역으로 진입하고, 게임 안의 재시작은 기존 Game 흐름을 유지합니다.

## 문구와 그림 교체

`Assets/Nomad/MainMenu/MainMenuContent.asset`의 Inspector에서 제목·프로젝트명·설명·버튼·하단 문구·배경을 바꿉니다. 로고를 지정하면 제목 텍스트 대신 표시하며, 비우면 제목으로 돌아옵니다. 배경에는 글자를 넣지 않습니다. 로고 이미지 자체의 글자를 바꾸려면 해당 이미지 수정이 필요합니다. 변경 후 다시 빌드해야 합니다.

제목은 영역 안에서 자동 축소하며, 원하는 위치에서 직접 줄바꿈해 2줄로 배치할 수 있습니다. 설명은 2~3줄 내에서 확인하며, 영역을 넘는 긴 문구는 프리팹의 해당 RectTransform과 글꼴 크기도 조정합니다. 길이에 제한 없이 모든 문장을 표시하는 구조는 아닙니다. 동작은 버튼 이름 문자열이 아니라 별도 이벤트로 연결됩니다.

## 설정과 입력

마우스 또는 위/아래 방향키·Enter로 조작합니다. 설정에서 좌/우 방향키 또는 마우스로 전체 음량을 조절하고 전체 화면을 선택합니다. Esc 또는 돌아가기로 메인 메뉴에 복귀합니다. 설정은 PlayerPrefs에 저장합니다. 음량은 전역 AudioListener에 적용되며 SFX/BGM 분리 설정은 범위 밖입니다. Editor의 종료 버튼은 Play를 멈추며 Windows 빌드는 앱을 종료합니다.

## 개발 도구와 검증

- `Nomad > Main Menu > Open Main Menu`: 씬 열기
- `Nomad > Main Menu > Register Startup Scene`: 기존 씬 목록을 보존하고 메뉴를 첫 씬에 등록. Game authoring 도구로 빌드 목록을 재생성한 경우 다시 실행합니다.
- `MainMenuAuthoring.Create`: 최초 콘텐츠·프리팹·씬을 생성하며, 기존 파일의 사용자 편집은 덮어쓰지 않습니다.
- `MainMenuTests`: 한글 문구 교체·여러 화면 비율 렌더·실제 입력·음량 저장·Game/Village 시작 검증
- `Artifacts/main-menu`: 검증 중 생성한 PNG. 사람의 색감·배치 수용 판단은 별도입니다.

참고: 첨부된 글자 없는 야영지 이미지를 배경으로 사용했습니다. 시안의 장식 로고는 기본 텍스트 로고로 표현하며 최종 로고는 콘텐츠 에셋에서 교체할 수 있습니다.
