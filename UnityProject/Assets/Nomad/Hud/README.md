# 플레이어 HUD 시안

Unity 6000.6.9f1에서 `Nomad > HUD > Open Preview`를 열고 Play합니다.

- WASD 이동, 좌클릭 사격, Shift 구르기, Space 점프.
- H: 실제 체력 25 감소, M: 마나 시안값 변경, T: 스태미나 시안값 변경, R: 초기화.
- 붉은 체력은 기존 Health를 읽습니다. 마나·스태미나·무기 이름은 미리보기 데이터입니다.
- 하단 슬롯의 인벤토리 드래그 등록은 아래 전용 미리보기에서 확인합니다. 장비 전환·아이템 사용·탄약 규칙은 구현하지 않았습니다.
- 기존 필드/몬스터 통합 씬은 수정하지 않았습니다.

다른 플레이어에는 `PlayerHud`를 추가합니다. 같은 오브젝트 또는 부모의 Health를 자동 연결하며 Inspector에서 직접 지정할 수도 있습니다. 자원 시스템은 `SetResources`, 장비 시스템은 `SetWeapon`으로 표시를 갱신할 수 있습니다. 미연결 자원은 `--`로 표시합니다. HUD는 입력을 가로채지 않습니다.

`Nomad > HUD > Verify Preview`는 전용 씬을 다시 만들고 체력·게이지·배치·비활성/재활성·재시작을 검증합니다. 검증용 렌더 결과는 UnityProject/Artifacts/hud에 저장됩니다. 실행 전 변경 중인 씬은 저장해야 합니다.

도형과 무기 실루엣은 코드로 그린 임시 시안입니다. 글꼴은 Unity uGUI 2.6.0 번들 TMP Essential Resources의 Liberation Sans SDF와 원본 TTF입니다. Fonts의 OFL을 함께 보존했습니다. 필요한 TMP Mobile SDF 셰이더와 include는 같은 번들에서 가져왔으며 Shaders/Unity-LICENSE.md를 보존했습니다. 별도 GUID를 사용해 이후 TMP Essentials 가져오기와 충돌하지 않도록 했습니다. 현재 라벨은 영문이며 한국어 표시에는 별도 CJK 글꼴 구성이 필요합니다.

TMP가 처음 사용되는 프로젝트를 위해 Hud/Resources의 기본 TMP Settings를 함께 제공합니다. 기존 TMP 설정이 있는 프로젝트에서는 해당 설정을 우선 사용합니다.

## 기존/중세 판타지 비교

현재 선택한 패널·무기 슬롯 스타일로 고정됩니다. 비교 버튼은 숨겨지고 F6 전환도 비활성화됩니다. R 초기화 후에도 현재 스타일을 유지합니다. 비교 구현은 개발 검증용으로 보존하며 HudPreview의 enableStyleComparison을 명시적으로 켰을 때만 사용할 수 있습니다.

새 스타일은 가죽색 패널·무기 슬롯 배경과 차분한 황동 테두리·작은 금속 장식에만 적용합니다. 마나·스태미나 링의 크기/두께/색상과 수정·번개 아이콘, 선택 슬롯의 기존 주황색 강조는 두 스타일에서 동일합니다. 회색 금속 원환과 장화 아이콘은 사용하지 않습니다. 체력 막대·하트·수치, 글꼴·문구·배치·기존 무기 실루엣은 유지합니다. 슬롯 숫자는 비교용 표시이며 장착 조작은 아닙니다.

검증 렌더는 `hud-original-{해상도}.png`와 `hud-medieval-{해상도}.png`로 분리합니다. 옵션 버튼은 사격을 차단하며 하단 HUD는 입력을 받지 않습니다.

## 인벤토리 ↔ 퀵슬롯 등록·해제

`Nomad > HUD > Open Quick Slot Preview` → Play → Tab으로 가방을 열고 아이템을 하단 1~4 슬롯에 드래그합니다. 기존 슬롯에 놓으면 등록을 교체하고, 같은 아이템을 여러 슬롯에 등록할 수도 있습니다. Esc·Tab·포커스 이탈·가방 내용 변경은 드래그를 취소합니다. 슬롯 밖에 놓으면 기존 상태를 유지합니다.

등록은 가방 아이템의 바로가기이며 수량을 옮기거나 소모하지 않습니다. 아이콘이 없으면 이름을 표시합니다. 중첩 가능한 아이템은 전체 스택의 합산 보유량을 표시합니다. 무기·방어구(현재 공용 규격의 최대 중첩 1)는 여러 개 보유해도 퀵슬롯과 드래그 미리보기에 수량 없이 아이콘 하나로 표시합니다. 가방의 장비는 기존처럼 한 칸에 하나씩 보관합니다. 가방 칸 이동 후에도 유지하며 해당 아이템이 모두 없어지면 등록을 해제합니다. 등록된 퀵슬롯 아이템을 가방 창 안으로 드래그하면 해당 슬롯의 등록만 해제합니다. 가방의 빈 칸·기존 아이템 칸·여백 어디든 놓을 수 있고 가방이 가득 차도 가능합니다. 가방 아이템의 수량·위치는 그대로이며 같은 아이템의 다른 퀵슬롯 등록도 유지합니다. 클릭만 하거나 가방 밖에 놓으면 해제하지 않습니다.

현재 등록은 플레이 세션 한정이고, 숫자키 장착·아이템 사용은 포함하지 않습니다. 미리보기의 숫자 1~3은 기존 가방 데모의 추가/제거 키입니다.

다른 씬에서는 `PlayerInventory`가 있는 플레이어 또는 그 자식에 `PlayerHud`를 추가합니다. HUD가 같은 플레이어의 `PlayerQuickSlots`를 준비하며 가방 패널이 해당 HUD의 좌표로 드롭을 판정합니다. 다른 플레이어의 HUD에는 등록하지 않습니다. HUD 그래픽은 기존처럼 입력을 가로채지 않으며 숨겨진 HUD에는 드롭할 수 없습니다.

`Nomad > HUD > Verify Quick Slots`는 전용 씬을 생성하고 가상 마우스·키보드로 등록/교체/드래그 해제/취소, 수량 갱신과 소진 시 해제를 검사합니다. 렌더는 `UnityProject/Artifacts/quick-slots/registered.png`에 저장합니다. 가방 이동과 상자 전송은 기존 검증을 별도로 실행합니다.
