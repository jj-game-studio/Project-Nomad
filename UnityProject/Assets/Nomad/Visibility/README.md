# 플레이어 시야 검토 (#114)

Unity 메뉴 `Nomad > Visibility > Open Visibility Demo` → Play. WASD 이동, 마우스 방향으로 부채꼴 시야를 돌립니다. 빨간 적은 정면/벽 뒤/등 뒤/덤불 안에 배치했습니다.
초기값: 거리24m, 각도120°, 눈높이1.2m, 판정0.08초, 가림 유예0.08초. Player Visibility Inspector에서 조절합니다.
`Build Field Preview`는 최신 TerrainIntegration을 VisibilityField.unity로 복사합니다. 원본 씬/생성기/몬스터 AI/구매 프리팹은 변경하지 않습니다.
정식 Game/PlayerRig 연결은 #89/PR95 담당자와 조율 후 진행합니다. 모든 게임 씬에 자동 적용하지 않습니다.

## 표시 규칙

적 몸통/머리/양옆 중 하나라도 거리·각도·장애물 검사를 통과하면 표시합니다. 근접 후방 감지는 없습니다.
Renderer.forceRenderingOff 및 체력바·피격 숫자만 제어하고 Collider·Health·AI·공격은 유지합니다.
새 Renderer도 LateUpdate에서 반영합니다. 스킬 예고는 적 소속 Renderer와 함께 숨깁니다.
이미 발사된 독립 발사체/소리/독립 사망 드롭은 적 표시와 별개입니다.

식생은 눈높이 방사선256개의 도달 거리를 셰이더에 전달합니다. 부채꼴의 보이는 구간에서 윗부분만 잘라냅니다.
덤불은 지면 위0.4m, 나무는 줄기1.5m를 남기는 검토 초기값입니다. 줄기 충돌은 유지하고 잎은 시선을 막지 않습니다.
자동 연결은 FieldDressing 루트의 tree/bush/fern/leaves 이름을 사용합니다. 다른 이름은 VisibilityFoliage를 명시적으로 붙입니다.
바위/벽/울타리와 기존 큰 덤불 제외 규칙은 변경하지 않습니다.

## 제한과 검토

- 덕코프 내부 구현 복제가 아닙니다. 각도/거리·가림 유예·식생 표현과 공격 예고 숨김은 사람 플레이 수용 대상입니다.
- 식생 마스크는 눈높이 수평 근사여서 경사지/높은 수관에서 적의3D 판정과 다를 수 있습니다.
- 재질은 BaseMap/색상/UV/Alpha Cutoff를 복사합니다. 특수 바람/금속/노멀 효과는 재현하지 않습니다. 원본을 보존하고 해제 시 복원합니다.
- 한 플레이어/한 시야 모듈이 대상입니다. 다중 관찰자/분할 화면은 제외합니다.
- 생성 필드는 별도 복사본에서 검토합니다. 실제 구매 식생/지역 전환과 성능 수용은 별도 기록합니다.

## 검증

`Nomad > Visibility > Verify Visibility`로 실제 마우스 방향, 벽/낮은 엄폐물/고저차, 숨긴 적의 피해/충돌, 동적 효과, 모듈/관찰자 해제 및 식생 재질 복원을 검사합니다.
검증 결과와 렌더는 PR에 기록합니다. 렌더는 사람 조작 검토와 구분합니다.


## 메인 게임 모듈 연결

PlayerVisibilityModule.prefab은 씬 참조 없이 활성 PlayerMovement를 찾아 연결합니다.
#89 담당자와 합의한 뒤 GameConfig.modules에 이 프리팹을 등록하면 영속 플레이어에 연결할 수 있습니다.
등록 파일은 이번 PR에서 수정하지 않습니다. 저장 프리팹의 생성/해제와 자동 바인딩은 전용 Play 검사에서 확인합니다.
